# 禾兴时光 Harvest Tales

> 基于Unity引擎开发的乡村主题休闲治愈模拟经营游戏，融合休闲玩法与乡村振兴社会价值，打造沉浸式田园生活体验

---

## 一、项目简介

《禾兴时光》是一款以乡村生活为核心，将**休闲治愈玩法**与**乡村振兴社会价值**深度融合的3D模拟经营游戏。玩家将化身返乡青年，在禾乡村落中通过种田、垂钓、经营、社交等玩法，亲手将荒废的村落打造为繁荣的特色农庄，沉浸式体验乡村振兴的成就感与乡土文化传承的意义。

项目除游戏本体开发外，未来规划搭建数字农场，实现产教融合，助力不同地域季节性农产品的推广与销售，让游戏的社会价值从虚拟延伸至现实。

## 三、游戏定位与目标受众

### 1. 低龄儿童

- 吸引力：卡通可爱的美术风格、简单易上手的点击操作、播种收获的即时正向反馈
- 核心价值：通过种植经营学习基础数学运算与商业常识，在NPC互动中提升语言表达与社交能力，培养耐心与责任感

### 2. 青少年

- 吸引力：慢节奏治愈氛围缓解学业压力，种植、垂钓、经营等多元玩法满足探索与创造需求
- 核心价值：在农庄规划与资源管理中锻炼战略思维，在社交互动中提升团队协作能力，深化对乡村文化与乡村振兴的认知

### 3. 工薪阶层上班族

- 吸引力：碎片化时间即可游玩，温馨治愈的田园氛围缓解工作压力，告别快节奏竞争的休闲体验
- 核心价值：满足对田园生活的向往，获得虚拟世界的成就感与情感寄托，舒缓日常焦虑与疲惫

## 四、游戏背景

在名为禾乡的古老村落，因青壮年持续外出务工逐渐走向衰落，大片农田荒废、乡土传统技艺濒临失传。玩家将扮演返乡青年，受村长委托，凭借现代农业技术与文化创新思路，带领村民盘活村落资源，一步步将禾乡打造为远近闻名的「特色农产品创业示范村」，实现乡村的全面振兴。

## 五、核心玩法与系统设计

### 1. 种植系统

游戏核心玩法，完整还原农作物从播种到收获的全周期：

- 玩家可在商店购买辣椒、南瓜、西瓜、番茄等多种果蔬种子，种子自动存入背包
- 按`I`键打开背包，将种子拖入快速物品栏，通过键盘数字键切换选中种子
- 走到田地附近，鼠标准心对准土壤坑洞中心，点击左键即可完成播种
- 可购买锄头铲除已种植的作物，更换种植品种；购买喷壶浇灌作物，加快生长进度
- 作物生长与时间系统深度联动，分为一次性成熟与多次成熟两类，多次成熟作物可反复采摘果实

### 2. 钓鱼系统

- 在商店购买鱼竿后，可前往池塘区域进行垂钓
- 鱼儿上钩后，需通过左右移动控制钩索，保持在鱼图标附近达到指定时长，即可成功钓起
- 内置12种不同鱼类，每种鱼有独立的上钩难度与概率，难度越高的鱼类，商店出售价值越高

### 3. 商店与经济系统

- 商店提供种子、农具、鱼饵等全品类道具，支持玩家购买与出售物品
- 玩家可通过出售成熟农作物、钓获的鱼获获取金币，金币可用于购买生产资料、扩充经营规模
- 完整的经济循环闭环，通过商品买卖的差价实现财富积累，推动农庄发展与游戏进度推进
<img width="1013" height="703" alt="image" src="https://github.com/user-attachments/assets/b2bc45dc-9ed3-4b9b-9601-9347134cd540" />


### 4. NPC交互与任务系统

- 采用对话树结构搭建人机对话系统，每个NPC拥有独立的对话内容与任务线
- 玩家与NPC交谈时，选择不同对话选项会触发对应回复，推进剧情发展、解锁新任务或获取关键游戏指引
- 任务状态全程自动记录，完成当前任务后自动解锁下一阶段任务，引导玩家熟悉游戏全玩法

### 5. 时间与气候系统

- 完整的昼夜轮换机制，游戏内时间、季节、天气实时显示在UI界面
- 可自定义昼夜时长，不同时段对应专属天空盒材质，营造沉浸式时间流逝体验
- 随机天气系统（如下雨），天气变化会直接影响作物生长速度，丰富玩法随机性
<img width="1201" height="811" alt="image" src="https://github.com/user-attachments/assets/26b000ef-d9cb-4d2e-831f-c115d4c39b6d" />


### 6. 野兽驱赶系统

- 地图内会随机刷新野兽，模拟现实中农户面临的野生动物侵扰场景

- 玩家可在商店购买对应道具，对野兽进行驱赶，保护农田与作物

- 基于碰撞检测技术实现道具与野兽的交互，触发对应的驱赶反馈与奖励机制

## 七、项目开发流程

1.  **策划阶段**：完成需求分析，确定游戏风格、核心玩法，明确功能性与非功能性需求，制定完整的游戏设计方案
2.  **系统设计阶段**：完成游戏整体框架搭建、功能模块拆分，设计各系统逻辑关系与交互规则
3.  **开发实现阶段**：完成游戏主界面、核心玩法系统、通关指引流程的开发，实现所有预设功能
4.  **测试优化阶段**：游戏打包后开展全量测试，根据测试结果修复漏洞、优化性能与游戏体验
